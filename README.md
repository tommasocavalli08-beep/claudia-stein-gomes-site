# Dra. Claudia Stein Gomes — Cirurgia Vascular

Site institucional em **Next.js 16.3.3 (Active LTS)** para a Dra. Claudia Stein Gomes (CRM-PR 16064 · RQE 9991), cirurgiã vascular em Curitiba.

## Destaques técnicos
- App Router e páginas estáticas indexáveis
- SEO local e metadados por página
- Schema.org: Physician, MedicalClinic, WebSite, WebPage e ScholarlyArticle
- `sitemap.xml`, `robots.txt` e `llms.txt`
- Conteúdo estruturado para GEO / AI Search
- Design responsivo e acessível
- Links diretos para WhatsApp, Doctoralia e Google Maps
- Política de privacidade / LGPD

## Desenvolvimento
`npm install && npm run dev`

## Produção
`npm run build && npm start`

Defina `NEXT_PUBLIC_SITE_URL` quando houver domínio próprio.
